# Security Policy

Private Rollup is currently an MVP / functional prototype.

Do not use this repository as production-grade secure storage without an
independent review of:

- Browser encryption and key lifecycle.
- HPKE wrapping and recovery material handling.
- Payment Vault Move contract logic.
- Backend upload authorization and staging controls.
- Shelby pack settlement and receipt verification.

## Reporting issues

Please open a GitHub issue for non-sensitive security hardening suggestions.

For sensitive vulnerabilities, contact the repository owner privately before
publishing details.
